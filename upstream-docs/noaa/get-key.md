# Request Web Services Token

To gain access to NCDC CDO Web Services, register with your email address. An email will be sent with a unique token which will allow access RESTful services. For more information about CDO Web Services read the documentation for CDO Web Services guide.

An email has been sent containing your CDO web services token.

Submit

### Submit your email address

- Enter your email address into the field above.

- Click on the SUBMIT button.

### Next, check your email

- If you have not requested a token before a token key will be generated and sent to the email address provided.

- If the email address has been previously registered our system will send a reminder email containing your unique token.

### Utilize the CDO Services

- Read and use the online documentation to learn how to access specific data.

- Once you have your token, you may begin using the RESTful URIs to mine data from the CDO services.
