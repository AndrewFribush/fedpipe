## NSDE Overview

For more information about NSDE, please see the following section of the FDA SPL website: FDA Comprehensive NDC SPL Data Elements.

### Key Facts

- Source of the data:
NDC SPL Data Elements

- Changes to the source data:
openFDA may change some field names and converts the data into JSON, which is a widely used machine readable format.

- Time period covered in this API:
2009 to null

- Frequency of API updates:
Daily
